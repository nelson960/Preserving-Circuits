# Preserving Circuits

Research on continual learning through mechanistic interpretability, representation drift, and causal feature preservation.

The project studies what changes inside a model when sequential training breaks old behavior: feature movement, readout misalignment, route drift, causal-use changes, and capacity collision.

Current work:

- inspect latent representations in small language models;
- track feature drift before and after fine-tuning;
- distinguish decodable features from causally used features;
- build visual tools for representation geometry and circuit drift.
